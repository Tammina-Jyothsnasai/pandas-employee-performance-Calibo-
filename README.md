# 📊 Employee Performance Data Analysis using Pandas

This project demonstrates **data analysis and data cleaning using Python and Pandas** with an Employee Performance dataset stored in Excel format.

The project is created as part of my **Pandas learning and practice** during the Calibo learning journey.

## 📁 Project Files

```text
pandas-employee-performance-Calibo-
│
├── practice(pandas).ipynb
├── Employee_Performance_Data.xlsx
└── README.md
```

### `practice(pandas).ipynb`

A Jupyter Notebook containing Pandas operations and practical examples for working with employee performance data.

### `Employee_Performance_Data.xlsx`

An employee performance dataset containing employee-related information such as department, experience, salary, attendance, projects, training, productivity, satisfaction, and performance scores.

The dataset also contains **missing values** to practice data-cleaning operations in Pandas.

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Jupyter Notebook
* Microsoft Excel

## 📚 Pandas Operations Covered

The notebook focuses on important Pandas operations such as:

* Importing and reading Excel data
* Creating and inspecting DataFrames
* Viewing rows using `head()` and `tail()`
* Checking rows and columns
* Understanding DataFrame shape
* Checking data types
* Handling missing values
* `isnull()` and `notnull()`
* `fillna()`
* `dropna()`
* Filtering data
* Sorting data
* Selecting columns and rows
* `groupby()`
* Aggregation functions
* Calculating mean, sum, minimum and maximum
* Creating new columns
* Basic employee performance analysis

The main purpose of this project is to gain practical experience in:

1. Working with real-world style datasets.
2. Loading Excel files using Pandas.
3. Identifying and handling missing data.
4. Cleaning and transforming data.
